4. 追加機能（原本に記載のない新規スコープ）

以下は原本（v1.2 / v1.0）に機能要件としての記載がなく、追加でご依頼いただいた機能です。いずれも実装・動作確認済みです。

4-1. 自動売買 枠・キャパ・受注管理

  • 加盟店ごとの保有枠（エコノミー=1枠／上位=2枠デフォルト、最大10枠）。
  • 有効枠 = min(保有枠, 自動売買用の預かり金 ÷ 1枠あたり運用資金)。
  • 預かり金 100万円未満は受注ロック。1枠あたり運用資金は既定400万円（加盟店ごと本部設定可）。
  • 全体200台の同時運用上限（設定値で拡張可）と使用率の可視化。
  • 受注待ち（予約）：上限到達時に登録。先着順＋本部の手動並替、空き発生時の割当。

4-2. 枠購入（請求・入金消込 連動）

  • 上位プランの3枠目以降を10万円/枠（税抜）＋消費税で購入。
  • 請求発行 → 入金消込の完了で保有枠を自動付与（最大10・二重付与防止）。

4-3. 月額管理手数料（枠数連動・月次）

  • 月額 =（保有枠数 − 1）× 単価（既定10万円・税抜）＋消費税。
  • 本部が月次で実行（加盟店ごと／全社一括）。満了月単位で数え、端数月は課金しない。
  • 預かり金から相殺し、不足分は請求（デポジット依頼）＋通知を発行。受注は継続。
  • 既存加盟店は機能適用日を起算とし、遡及課金なし。

4-4. 消費税対応

  • 月額管理手数料・枠購入費用に消費税を自動加算。
  • 税率は本部管理画面で変更可能（法改正対応）。税抜／消費税／税込を表示・記録。

4-5. 予算振り分け（両フロー保有者）

  • 自動売買・半自動の両方を持つ加盟店が、預かり金を用途ごとに振り分け。
  • 各フローの受注可否・発注上限に連動。

4-6. 進捗フローの段階制限・仕入れエビデンス

  • 自動売買の進捗フローを、現フェーズは「販売中・精算完了」の2段階で運用（「仕入れ中」は第二フェーズから拡張・予告表示）。ロジックは全段階を構築済み。
  • 販売中の車両に、本部が仕入れデータのエビデンスを1点添付（画像/PDF）。加盟店は閲覧のみ。

4-7. 運転資金の出金（引き出し）機能

  • 加盟店の出金申請、オーダー中・仕入れ中は申請ロック、チケット制による回数管理。
  • 出金手数料を差し引いて振込。本部の承認・却下、振込用CSV出力、振込完了で預かり金から自動減算。
  • ※チケットの詳細仕様（デフォルト枚数・購入制・不足時の扱い・最低残高）は別途確定のうえ反映。

4-8. 車両進捗管理の仕上げ（Phase 3 推奨機能）

  • 結果報告書のドラッグ＆ドロップ取込（加盟店も閲覧可）。
  • 商品化チェックリスト（点検・清掃・撮影・掲載準備）。
  • 販売実績に平均在庫日数・回転率を追加。

4-9. 本部の一覧ページ整備

  • 契約管理（全加盟店の契約横断一覧）・請求・入金管理（全加盟店の請求横断一覧）の専用ページ。

5. 設計方針の変更（原本からの変更点）

5-1. データ基盤：Notion CRM連携 → 独自データベース

  • 原本（v1.0）は「当面 Notion CRM をマスターとし、将来的に独自DBへ移行」を想定。
  • 本システムは初めから独自データベース（Supabase / PostgreSQL）で構築しており、原本が将来推奨としていた独自DB構成を先取りしています（Notion連携は実装しません）。
  • これに伴い、加盟店管理・契約・入金・対応状況などは独自DB上で一元管理します。

5-2. 管理手数料：成約ごと → 枠数連動の月額

  • 原本（v1.0 PLAN-03）は「成約ごとの管理手数料」を想定。
  • 後続のご指示により、「枠数に応じた月額（毎月）」へ設計を変更しています（4-3 参照）。

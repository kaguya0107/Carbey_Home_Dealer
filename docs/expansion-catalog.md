# 拡張機能カタログ（たたき台）

システム全体の「拡張可否」を分野横断で一本化した一覧。加盟者が事業展開のイメージを持ち、拡張を申し出やすくする（＝収益機会を増やす）ことが目的。

- **金額の扱い**：AI系の任意拡張は「β稼働後の実測をふまえて確定」。すでに単価が決まっている項目（枠購入・出金チケット等）は確定額を記載。大型構想は「個別見積」。
- **可視化方針**：各機能の拡張可能項目に〈拡張可〉アイコンを付与し、加盟者の左メニューから「拡張機能一覧ページ（`/portal/expansions`）」で確認・申し出できるようにする（当初の要件スコープ「拡張オプションの表示・拡張案件プロセス」に対応）。

## 凡例

- **区分**：`AI` … Phase 4 AI機能／`運用` … 売買・業務系／`将来` … 大型別フェーズ
- **金額**：`確定` … 単価確定済／`β後` … β稼働後に確定／`個別` … 個別見積

## 加盟者向け可視化（当初スコープの具体化）

- **〈拡張可〉アイコン**：上記の拡張可能項目に該当する画面・メニューへバッジを表示。
- **拡張機能一覧ページ `/portal/expansions`**：分野別に「できること／準備物」を掲載し、「拡張を申し出る」導線（本部への申請）を設置。金額欄は確定分は表示、AI系は「β稼働後に確定」表記。
- 申し出 → 本部が内容・金額を提示 → 合意 → 開放（設定変更 or 実装）という拡張案件プロセスにつなげる。

> 金額欄の運用：確定済みは金額表示、AI系任意拡張は「β稼働後に確定」、大型構想は「個別見積」。内容が固まり次第、順次確定額へ差し替える。
